🛡️ Currency Rate Guard

Stop documents from being posted or confirmed in a foreign currency when today's exchange rate is missing — and let accountants enter the rate on the spot.

✨ Key Features

  • Mark any currency as Require Daily Rate from the Currencies list or form
  • Blocks confirming purchase orders, posting vendor bills & customer invoices, and posting payments in a guarded currency when today's rate is missing
  • Shows a clear, actionable warning with a one-click Enter Today's Rate button
  • A quick-entry wizard registers today's rate without leaving your workflow
  • Multi-company aware — the rate is checked per company
  • Interface translated into 90+ languages

✅ Compatibility

  • Odoo version: 19.0, 18.0
  • Editions: Community and Enterprise
  • Hosting: Odoo.sh, On-Premise

🛠️ Usage

  • Open Accounting → Configuration → Currencies and tick Require Daily Rate on each currency you want guarded.
  • When a document in that currency is confirmed/posted without today's rate, a warning appears.
  • Click Enter Today's Rate, type the rate, and Save Rate.
  • The document can then be posted or confirmed as usual.

📦 Installation

  • Copy the module to your Odoo addons directory
  • Update the app list
  • Install the module from the Apps menu
