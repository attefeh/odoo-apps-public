🚫 Disable Tours

Permanently switch off all of Odoo's onboarding tours — for every user, across both the backend and the website — with nothing to configure.

✨ What It Does

  • Disables the floating onboarding tours (the green helper bubbles) for all users
  • Works on both ends — backend and frontend (website)
  • Server-side: tour_enabled is always reported as False, so the tour service never resumes a tour at page load, and the developer-tools toggle becomes a no-op
  • Client-side: the tour_service is replaced with a no-op, so even a manual startTour() call does nothing
  • Zero configuration — once installed, tours stay off

✅ Compatibility

  • Odoo version: 19.0
  • Editions: Community and Enterprise
  • Hosting: Odoo.sh, On-Premise and Odoo Online (SaaS)

📦 Installation

  • Copy the module to your Odoo addons directory
  • Update the app list
  • Install the module from the Apps menu — that's it, no settings to change
